# طلب إعداد البريد الإلكتروني الرسمي للنطاق t3leem.my

**إلى:** فريق الدعم الفني في شركة الاستضافة
**الموضوع:** إنشاء صندوق بريد `t3leemy@t3leem.my` وتفعيل الإرسال عبر SMTP من الخادم

السلام عليكم ورحمة الله،

لدينا منصة تدريب سحابية على النطاق **t3leem.my** (الخادم: `187.126.12.45`). نحتاج صندوق بريد رسمياً تُرسَل منه رسائل المنصة، وأهمها **رمز الدخول المؤقت (OTP)** المكوّن من ٦ أرقام الذي يصل إلى المستخدمين، لأن الدخول إلى المنصة صار يعتمد عليه بالكامل. إن تعذّر الإرسال لن يستطيع أحد الدخول، فنرجو العناية بالإعداد واستقرار وصول الرسائل إلى صندوق الوارد وليس البريد غير المرغوب.

## المطلوب

1. **إنشاء صندوق البريد** `t3leemy@t3leem.my` بكلمة مرور قوية (لا نريدها في أي رسالة بريد؛ نرجو إرسالها عبر قناة آمنة أو عبر لوحة التحكم، أو نضعها نحن من لوحة الاستضافة).
2. **تفعيل الإرسال عبر SMTP** بمصادقة (اسم مستخدم وكلمة مرور) من عنوان الخادم `187.126.12.45`، على أحد المنفذين:
   - المنفذ **465** مع **SSL/TLS** (المفضل)، أو
   - المنفذ **587** مع **STARTTLS**.
3. **التأكد أن الاتصال الصادر من الخادم إلى خادم البريد على المنفذ 465 أو 587 غير محجوب** (نعلم أن المنفذ 25 يُحجب غالباً، ولا نحتاجه).
4. **إضافة سجلات DNS للنطاق** لضمان وصول الرسائل إلى الوارد:
   - **SPF**: سجل TXT على `t3leem.my` يسمح بخادم البريد وبالعنوان `187.126.12.45`، مثل: `v=spf1 a mx ip4:187.126.12.45 include:<نطاق خادم البريد لديكم> ~all`
   - **DKIM**: تفعيل التوقيع للنطاق وإضافة سجل TXT الخاص به.
   - **DMARC**: سجل TXT على `_dmarc.t3leem.my`، مثل: `v=DMARC1; p=none; rua=mailto:t3leemy@t3leem.my`
   - **MX**: التأكد من وجود سجل MX صحيح للنطاق (لاستقبال الردود).
   - **PTR (Reverse DNS)** للعنوان `187.126.12.45` يشير إلى اسم يخص النطاق (إن أمكن).
5. **حدود الإرسال:** الاستخدام المتوقع من عشرات إلى بضع مئات من الرسائل يومياً (رموز دخول وإشعارات). نرجو ألا يكون الحد اليومي أو في الساعة أقل من ٥٠٠ رسالة يومياً و٦٠ في الساعة.

## ما نحتاجه منكم في الرد

| البند | القيمة |
|---|---|
| خادم SMTP (Host) | |
| المنفذ (Port) | 465 أو 587 |
| نوع التشفير | SSL/TLS أو STARTTLS |
| اسم المستخدم | `t3leemy@t3leem.my` (أو غيره إن اختلف) |
| كلمة المرور | تُرسل بقناة آمنة |
| الحد اليومي / الساعي للإرسال | |
| تأكيد إضافة SPF وDKIM وDMARC وPTR | |
| تأكيد أن المنفذ الصادر 465/587 مفتوح من `187.126.12.45` | |

## معلومات تقنية (للمرجع)

- النطاق: `t3leem.my`
- عنوان الخادم المرسِل: `187.126.12.45`
- العنوان المرسِل: `T3leem.my <t3leemy@t3leem.my>`
- نوع الرسائل: رسائل نصية و HTML قصيرة (رمز تحقق، إشعار اعتماد اشتراك).
- نوع الاتصال: SMTP مصادَق عليه (AUTH LOGIN/PLAIN) فوق TLS، من تطبيق Node.js (مكتبة nodemailer).

## بعد الإعداد

سنختبر الإرسال برسالة حقيقية، وإن وصلت إلى البريد غير المرغوب سنراسلكم لضبط السجلات.

شاكرين تعاونكم.
