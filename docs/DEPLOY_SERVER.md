# النشر على خادم خاص (VPS)

على خادم دائم تعمل **كل** الميزات، بما فيها رفع الفيديو وتشفيره (على عكس Vercel).

## ما يجهّزه السكربت تلقائياً
| المكوّن | التفاصيل |
|---|---|
| Node.js 22 | تشغيل الخادم الخلفي والواجهة |
| PostgreSQL | قاعدة `t3leem` بمستخدمين منفصلي الصلاحيات وسياسات العزل |
| Redis + عامل الفيديو | الطوابير، حدود الطلبات، تحويل الفيديو في الخلفية |
| Nginx | يستقبل المنفذ 80 ويوزّع: `/api/` للخادم الخلفي، والباقي للواجهة |
| systemd | ثلاث خدمات تعمل تلقائياً وتُعاد عند التعطل أو إعادة التشغيل |
| جدار حماية (ufw) | مفتوح فقط: SSH و80 و443. قاعدة البيانات وRedis غير مكشوفة |

الأسرار (كلمات مرور القاعدة، مفاتيح التشفير، مفاتيح JWT) **تُولَّد على الخادم نفسه** في أول نشر ولا تخرج منه، وتُحفظ في `/opt/t3leem/shared/`.

## النشر
من مجلد المشروع (Git Bash):

```bash
bash deploy/deploy.sh root@187.126.12.45 t3leem.my
```

- يُرفع **الكود الملتزم فقط** (`git archive`)، فلا يُرفع `.env` أو المفاتيح أو `node_modules` أبداً.
- مع النطاق يصدر السكربت تلقائياً شهادة **Let's Encrypt** مجانية لـ `t3leem.my` و`www.t3leem.my`، ويحوّل كل `http` وزيارات عنوان IP و`www` إلى `https://t3leem.my`، وتتجدد الشهادة تلقائياً.
- إن لم يكن DNS يشير للخادم بعد، يعمل الموقع مؤقتاً عبر `http` ويكفي إعادة النشر لاحقاً لإصدار الشهادة.
- كل نشر في مجلد إصدار مستقل، ولا يتحول الموقع إليه إلا بعد نجاح فحص صحة الخدمات؛ وعند الفشل يعود تلقائياً للإصدار السابق. يُحتفظ بآخر ٣ إصدارات.

## DNS (مُعدّ حالياً ✅)
| السجل | القيمة |
|---|---|
| `A` لـ `t3leem.my` | `187.126.12.45` |
| `CNAME` لـ `www` | `t3leem.my` |

## أوامر مفيدة على الخادم
```bash
systemctl status t3leem-api t3leem-web t3leem-worker   # حالة الخدمات
journalctl -u t3leem-api -f                             # سجل الخادم الخلفي مباشرة
ls -l /opt/t3leem/current                               # الإصدار الحالي
```

> ⚠️ PDPL: للإنتاج الفعلي يجب أن يكون الخادم داخل المملكة.
