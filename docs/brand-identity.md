# هوية T3leem.my البصرية

الشعار الرسمي: مبنى مدرسة يعلوه علم، فوق كتاب مفتوح، وقلم يكتب، وبجانبه مربعات رقمية، والاسم **t3leem.my**. الألوان مأخوذة من الشعار نفسه.

## الألوان

| الاسم | القيمة | مصدره في الشعار | الاستعمال |
|---|---|---|---|
| أزرق سماوي `--sky` | `#29B6F6` | «‎.my» والعلم والكتاب | خط الترويسة العلوي، لمسات التمييز، الأيقونات |
| أزرق العلامة `--brand` | `#0B7AB8` | درجة أغمق من السماوي لتحقق تباين ≥ 4.5 مع الأبيض | الأزرار الرئيسية والروابط (الافتراضي للمنصة) |
| رمادي أردوازي `--slate` | `#404858` | الاسم «t3leem» والقلم والمبنى | العناوين والنصوص الداكنة |
| ثلجي `--ice` | `#EAF6FD` | زجاج النوافذ والكتاب | خلفيات فاتحة وبطاقات تمييز |
| الخلفية `--bg` | `#F3F8FB` | | خلفية الصفحات |
| النص `--ink` | `#1F2937` | | النص الأساسي |
| النص الثانوي `--muted` | `#5B6676` | | الشروحات |
| الخط الفاصل `--line` | `#D8E2EB` | | الحدود |

الوضع الداكن: خلفية `#0D141D` وسطح `#141E2A` ونص `#E6EDF5`. يوضع الشعار والرمز دائماً على لوحة بيضاء مستديرة ولا يُعكس لونه.

الأكاديميات تحتفظ بلونها الخاص: لون المزود (`brand_settings.primaryColor`) يستبدل `--brand` داخل صفحاته فقط، أما صفحات المنصة (الرئيسية، الانضمام، لوحة الإدارة، التحقق من الشهادة) فتستعمل هوية المنصة.

## الملفات (`web/public/brand/`)

| الملف | الاستعمال |
|---|---|
| `logo-original.jpg` | الأصل 1536×1024 للطباعة والمواد التسويقية |
| `logo.jpg` | الشعار الكامل (الرمز + الاسم) 960×640 لصفحات الويب |
| `emblem.png` / `emblem-96.png` | الرمز وحده (مبنى + كتاب + قلم) بخلفية بيضاء مربعة |
| `og.jpg` | صورة المشاركة في وسائل التواصل 1200×630 |
| `web/app/icon.png` و`apple-icon.png` | أيقونة تبويب المتصفح وأيقونة الجوال |

## القواعد

- مساحة بيضاء حول الشعار لا تقل عن عرض حرف «t» من الاسم، ولا يُمدَّد ولا تُغيَّر ألوانه.
- أصغر حجم للشعار الكامل 160 بكسل عرضاً؛ دون ذلك يُستعمل الرمز وحده.
- الأزرار الرئيسية بـ `--brand` ونص أبيض؛ لا يُكتب نص أبيض على `--sky` (تباينه ضعيف).
- الخط: «Readex Pro» للعناوين و«IBM Plex Sans Arabic» للنص (كما في الموقع).
